# Fase de análisis
1. Leer el caso o las entrevistas y subrayar lo que el sistema debe hacer.
2. Separar los requerimientos funcionales (qué hace) de los no funcionales (cómo debe ser).
3. Redactar cada requisito en una sola frase, clara y medible (con números cuando se pueda).
4. Dar prioridad con MoSCoW (Must, Should, Could, Won't).
5. Guardar la lista en la carpeta docs/analisis.
