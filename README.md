# Entorno de trabajo para desarrollo de software

Este repositorio es un entorno de trabajo organizado por fases del desarrollo de software.

## Estructura
- .agent/skills/analisis: skill para la fase de análisis
- .agent/skills/diseno: skill para la fase de diseño
- .agent/skills/implementacion: skill para la fase de implementación
- .agent/skills/pruebas: skill para la fase de pruebas
- docs: documentos de cada fase
- src: código fuente

## Herramientas
- Git y GitHub para el control de versiones
- Visual Studio Code (o Antigravity) como editor
- Extensiones de GitHub y Figma
