# Fase de pruebas
1. Tomar la lista de requerimientos y escribir una prueba por cada uno.
2. Poner el resultado esperado de cada prueba (por ejemplo, responde en menos de 2 segundos).
3. Ejecutar las pruebas y anotar si pasaron o fallaron.
4. Corregir los errores y volver a probar.
5. Guardar los resultados en la carpeta docs/pruebas.
