# Fase de implementación
1. Crear una rama nueva en Git por cada funcionalidad (git checkout -b nombre-rama).
2. Programar siguiendo el diseño, con código simple y comentarios cortos.
3. Hacer commits pequeños con mensajes que digan qué se hizo.
4. Subir los cambios a GitHub con git push.
5. Guardar el código en la carpeta src.
